# Air Canvas

**Air Canvas** — интерактивный художественный инструмент, позволяющий рисовать в виртуальном пространстве с помощью жестов рук.

Проект разрабатывается в образовательных целях для изучения компьютерного зрения (Computer Vision), машинного обучения (Machine Learning) и творческого программирования (Creative Coding).

## Идея проекта

Основная цель — создать приложение, которое с помощью веб-камеры отслеживает движения рук и преобразует их в цифровые рисунки.

В дальнейшем планируется расширить функциональность: добавить распознавание жестов, различные художественные кисти, визуальные эффекты и собственные модели машинного обучения.

## Технологии

- **Python** — основной язык программирования.
- **OpenCV** — захват и обработка изображений.
- **MediaPipe** — определение ключевых точек кисти руки.
- **PyTorch** — разработка и обучение собственных ML-моделей (в перспективе).

## Этапы разработки

- [ ] **Этап 1.** Получение и отображение видеопотока с веб-камеры.
- [ ] **Этап 2.** Обнаружение руки и отслеживание ключевых точек.
- [ ] **Этап 3.** Рисование с помощью движения указательного пальца.
- [ ] **Этап 4.** Реализация управления с помощью жестов.
- [ ] **Этап 5.** Создание художественных кистей и визуальных эффектов.
- [ ] **Этап 6.** Разработка и интеграция собственных ML-моделей.

## Организация разработки

Проект развивается поэтапно. Каждый этап включает изучение необходимых технологий, самостоятельную реализацию, тестирование и анализ полученных результатов.

История изменений фиксируется с помощью Git.

Заметки о ходе разработки, возникших трудностях и принятых технических решениях сохраняются в `docs/progress.md`.
